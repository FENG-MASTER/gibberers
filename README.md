# 语言大爆炸 · 桌边助手

供 3～5 人面对面游玩的纯前端辅助工具。共用一台手机或平板，造词、读音和公共词典保留在纸上。没有账号、房间、后端或第三方运行时依赖。

## 本地预览

在此目录执行：

```sh
python -m http.server 8000
```

打开 <http://localhost:8000>。不能直接双击 `index.html`：牌库加载、模块和离线缓存需要 HTTP/HTTPS。

## 发布到 GitHub Pages

项目附带 `.github/workflows/pages.yml`，只发布网页与 `assets`，不上传原始文档目录到 Pages 站点。

1. 将项目提交到自己的 GitHub 仓库。
2. 仓库 Settings → Pages → Build and deployment，Source 选择 **GitHub Actions**。
3. 推送到 `main` / `master`，或在 Actions 中手动执行 **Deploy Pages**。
4. 成功后打开部署输出的网址。支持 `https://用户名.github.io/仓库名/` 子路径。

也可用从分支部署的方式：选择含 `index.html` 的分支根目录。不过这种方式会一并发布仓库中的文档文件，推荐使用上面的 Actions。

当前工作区尚未关联可用 Git 仓库；创建这些文件不会自动发布网站。

## 已实现

- 文明名称、3～5 位玩家、顺时针导师轮换。
- 第 0 世代：18 个基础词计数、四个必备含义检查、相遇仪式、五张绘图卡与指图标记。
- 导师私密选题；每轮一次重抽、两张任选，另一张放回牌堆底。
- 第 1～5 世代按 4 / 5 / 3 / 2 / 1 轮推进，共 15 轮。
- 启迪标记跨轮保留，按 5 / 4 / 3 / 2 / 1 补充，最多 5 个。
- 正式作答扣费、导师人工判定、免费辅助词、三种提示及其限制。
- 发展标记累计与可用数量、重复兑换新词、自动计算套组与奇迹替代。
- 可选启迪计时，默认关闭；1～120 分钟。到时只提醒，不自动判负。
- 自动保存、继续上局、最多 40 步撤销、存档导入导出、已揭晓回合记录。
- 手机与平板响应式布局、Web App manifest、Service Worker 离线缓存。

## 线下使用

1. 联网打开站点，等右上角显示“已可离线使用”。
2. 可通过浏览器菜单“安装应用”或“添加到主屏幕”；具体入口取决于浏览器。
3. 开局后按提示完成纸面造词。导师私下看题，选题后题目自动隐藏。
4. 启迪阶段大家面对面交流，工具只记录作答、提示和资源变化。
5. 每轮结束补写纸条并整理词典，再把设备交给下一位导师。

切到后台时，私密题目会隐藏；重新打开或导入对局不会自动展示秘密题目。准备阶段的题目和奖励类型不出现在公共屏幕。它是同桌玩家之间的遮挡措施，不提供对设备持有者的安全访问控制。

## 存档与计时

游戏与撤销历史保存在当前浏览器的 `localStorage`。建议只开一个工具页面；多页面不会实时同步。清除网站数据、隐私浏览限制、换设备等可能使存档不可用，重要对局可导出 JSON 备份。存档包含牌堆与当前题目，游戏中不要把文件内容展示给学生。

计时以截止时间计算，页面后台运行或关闭后时间仍继续流逝。暂停计时后则保留剩余时长。导入和撤销不恢复旧的计时截止时间，回到启迪时会重置并暂停；不影响游戏资源。

只在页面显示“已可离线使用”后断网。浏览器清理缓存后需要重新联网加载。HTTPS（或本机 localhost）才能注册离线服务。GitHub Pages 默认支持 HTTPS。

更新网页内容时，同时修改 `sw.js` 的 `CACHE` 版本。旧版本会持续服务当前打开的页面；新版本下载完成后，关闭该站点的所有页面再重新打开即可启用，避免对局中混用版本。不会清除本地存档。

## 规则与资料口径

- 按 `doc/语言大爆炸/语言大爆炸规则书-最终版.pdf` 的专家规则实现。
- 使用 Excel v3 的 76 张知识卡、380 项知识。表内“军事”在界面称为“武力”。多数发展图标在母表中标为推定，不将其宣称为全部经原卡核验。
- 第 0 世代图片来自用户提供的五张图片。原扩展名虽然为 jpg，实际编码为 PNG，网页资源已使用正确扩展名。
- 19～23 分显示“规则未定义等级”；没有自行补设规则。
- 提示用尽启迪标记后无法支付作答费用，会失败；使用前有明确提示。最后一个标记用于正式作答时，回答正确仍算成功。
- “心灵感应”须已添加本轮辅助词；应用阶段可以多次兑换发展奖励。用过的发展标记仍全部计分。
- 第五世代最后一轮保留应用与纸条整理步骤，完成后结算。
- 对局记录保存已揭晓的知识和资源操作，不保存玩家自造词的发音。

## 验证与维护

需要 Node.js 20 或更新版本，无需安装 npm 依赖：

```sh
npm test
```

从原 Excel 重新生成牌库、复制绘图：

```sh
python scripts/extract_cards.py
```

需要标准库即可运行提取脚本。更新资料后记得更新离线缓存版本。

自动测试覆盖牌库完整性、完整成功/失败对局、重抽、提示与作答边界、标记兑换、最优套组计分、存档格式校验及缓存资源存在性。真实浏览器的触控布局、安装与断网重开还需按 `tests/MANUAL.md` 实测。
