# 浏览器验收清单

尚未在本工作环境进行真实浏览器实测。推荐 Chrome Android 与 Safari iOS 各走一次，桌面浏览器辅助验证。

1. 通过 HTTP/HTTPS 打开。手机 360px、平板 768px、桌面 1280px 宽度均无横向溢出；所有按钮可触达。
2. 首次加载后右上显示“已可离线使用”。关闭页面、断开网络，重新打开同一 URL：页面、牌库、五张绘图均可用。
3. 添加到主屏幕，确认图标与启动路径正确。在 `/仓库名/` 子路径重复第 2 步。
4. 新建 3 人、4 人、5 人对局，填写文明与座次；自定义计时默认隐藏，选自定义后出现。
5. 完成 18 个基础词、四个必备词、相遇仪式。未满足条件前不能推进。
6. 导师看题、重抽、选择任意一张任意一项；未选卡回牌堆底。选好后不泄露题目与奖励图标。
7. 导师复看期间切到另一应用再回来，题目被隐藏；刷新页面后只能从“继续上局”进入隐藏题目的状态。
8. 使用一次辅助词、三种提示；已使用的提示不能重复，不足以付费的提示禁用。祖先图片可切换、点击定位。
9. 最后一个标记作答并答对，仍成功；答错则失败；提示将耗尽标记时明确确认并失败。
10. 轮末补写纸条、兑换多个奖励、轮换导师；自动跨世代。已用发展标记仍计分。
11. 计时暂停、继续、后台再回来、重开页面均正确；时间到只提醒，不扣资源或自动失败。
12. 撤销选题、提示、判定、兑换、下一轮：状态恢复，题目隐藏，纸面同步提示明确。
13. 导出存档后新建另一局，再导入旧档：恢复玩家、牌堆、进度和计数；损坏或错误 JSON 显示错误，不覆盖旧档。
14. 完成 15 轮查看结算与历史；确认 19～23 分没有补设等级。
15. 含 `<script>`、引号等字符的文明或玩家名称按普通文字显示，不执行。
16. 更新 `sw.js` 缓存版本后发布：旧页面不被强制切换，关闭所有页面重开后新版生效，本地对局仍可恢复。

17. 导师点击“自己创造知识”，验证空含义/未选类型不能提交；前 3 世代单选，后 2 世代多选。提交即隐藏；复看、揭晓、历史显示正确。成功发放自定义类型标记、失败不发放；存档导入和撤销保留一致性。
18. 使用更新前的旧存档继续原有对局，再在下一轮创建自定义知识，确认兼容。
